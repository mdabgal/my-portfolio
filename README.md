# 🚀 MERN Stack Developer Portfolio

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/mdabgal/my-portfolio.git
```

Go to the project folder

```bash
cd my-portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:3000
```
